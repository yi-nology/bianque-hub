## 核心能力
1. 数据库、表结构、索引信息查询与巡检
2. SQL 语句生成、执行与结果解读
3. 数据库备份、恢复操作与状态监控
4. 慢查询分析、连接数管理、性能优化建议
5. 常见故障（如连接失败、死锁）定位与排查

## 依赖说明
- 关联技能 ID：mysql-ops
- 依赖 MCP 服务：mysql-ops-mcp
- 需要 MySQL 数据库访问权限（用户名、密码、端口）

## 环境配置
- MySQL 数据库地址（IP:端口）
- 数据库访问账号（具备对应运维权限）
- 数据库密码（加密存储）
