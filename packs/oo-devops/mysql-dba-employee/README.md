## 核心能力
1. MySQL 连接与状态查询
2. 慢查询日志分析与优化建议
3. 数据库表结构、索引、会话查看
4. 实时性能监控（连接数、QPS、锁等待、InnoDB 状态）
5. 常用 SQL 自动生成与执行
6. 数据库健康巡检与容量评估

## 依赖环境
- MySQL 5.7 / 8.0+
- 支持本地/远程数据库连接
- 需配置正确的数据库地址、端口、账号权限

## 适用场景
- 日常数据库巡检
- 慢 SQL 定位与优化
- 数据库状态监控
- 开发/测试环境快速查询
- DBA 日常工作自动化

## 注意事项
1. 使用前请确保数据库网络连通
2. 建议使用只读账号执行查询操作
3. 生产环境操作需谨慎，避免执行高危 SQL
