## 核心能力
1. Prometheus 监控指标查询、数据统计与分析
2. 告警规则查看、启用/禁用，告警信息排查
3. Prometheus 配置文件更新、服务重启
4. 监控目标状态巡检、异常排查
5. PromQL 查询辅助与表达式优化建议

## 依赖说明
- 关联技能 ID：prometheus
- 需具备 Prometheus 服务访问权限
- 依赖 Prometheus 服务正常运行（可访问 Web 端口）

## 环境配置
- Prometheus 服务访问地址（IP:端口）
- Prometheus 配置文件路径（可选，用于配置更新）
- 告警管理相关配置（可选）
