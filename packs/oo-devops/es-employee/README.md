## 核心能力
1. 集群健康状态检查与节点监控
2. 索引创建、删除、查看与模板管理
3. 日志检索与数据查询分析
4. 分片状态监控与性能分析
5. Mapping 管理与索引优化建议

## 使用配置
- ES_HOST：ES 服务地址
- ES_USERNAME：账号（默认 elastic）
- ES_PASSWORD：密码

## 适用场景
- 日志平台运维与检索
- 搜索服务性能管理
- 集群健康巡检
- 开发/测试数据查询与分析
