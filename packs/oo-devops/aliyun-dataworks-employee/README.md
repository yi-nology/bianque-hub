## 核心能力
1. 数据开发任务管理与运维
2. 任务运行状态实时监控
3. 任务日志自动检索与分析
4. 调度失败自动诊断与告警
5. 批量任务操作辅助与优化建议

## 使用配置
- DATAWORKS_AK_ID：阿里云 AccessKey ID
- DATAWORKS_AK_SECRET：阿里云 AccessKey Secret
- region-id：地域，默认 cn-hangzhou

## 适用场景
- 数据开发任务运维
- 离线调度监控与排错
- 数据任务日志排查
- 生产环境任务巡检
